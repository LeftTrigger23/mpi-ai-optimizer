The selector uses rank count and integers per destination. It defaults to MPI_Alltoall. The experimental tree uses its fitted prediction on measured configurations and falls back to the standard collective elsewhere.


  

  

    
Inside the exchange

    
Each rank has one send block per destination and one receive block per source. With MPI_Alltoall, the MPI library chooses how to move those blocks. The following rounds show the custom MPI_Sendrecv implementation.

    

      
      
    

    

    
Round zero exchanges a rank’s block with itself. In later rounds, the destination moves forward and the source moves backward, wrapping at the ends of the rank list.

    
What the benchmark measures

    
After 10 warmups, each rank averages 100 timed exchanges. The program reports the largest rank average. The bars show medians from five launches per algorithm. Each run checks the received values on every rank.
